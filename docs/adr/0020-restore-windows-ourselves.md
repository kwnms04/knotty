# 창 상태는 우리가 저장한다

창 프레임과 작업 디렉터리를 macOS 상태 복원에 맡기지 않고 `UserDefaults`에 직접
저장합니다. 작업 디렉터리는 OSC 7이 오지 않으면 포어그라운드 프로세스에서 직접
읽고, 저장은 주기가 아니라 사건에 겁니다.

## 맥락

M4가 창 복원을 짓습니다. 세 자리에 관례적인 길이 있고, 셋 다 우리 조건과
어긋납니다 — 그리고 셋 다 "당연히 그렇게 했겠지"의 반대라 나중에 하나씩
"고쳐질" 자리입니다.

## 근거

**NSWindowRestoration은 터미널에 비쌉니다.** macOS Tahoe의 상태 복원
데몬(`talagentd`)이 복원 가능한 창의 **내용이 바뀔 때마다** 스냅샷을 다시 뜹니다.
터미널은 내용이 끊임없이 바뀌는 창이라, 출력이 쏟아지는 동안 수 GB 디스크 쓰기와
로그인·잠금해제 지연으로 이어진다는 보고가 Ghostty에 올라와 있습니다
([#13354](https://github.com/ghostty-org/ghostty/discussions/13354)). 게다가 그
경로는 "앱을 종료할 때 창 닫기" 시스템 설정에 좌우되어, DoD F절이 요구하는 동작이
환경마다 달라집니다.

**그 기계가 필요한 이유가 우리에겐 없습니다.** Ghostty와 iTerm2가 그것을 쓰는
것은 스크롤백 내용까지 되살리기 때문입니다. [05-swift-app](../05-swift-app.md) 9절이
스크롤백은 복원하지 않는다고 이미 정했으므로, 우리가 저장하는 것은 창마다 사각형
하나와 경로 하나입니다.

**OSC 7은 기본 상태에서 오지 않습니다.** `/etc/zshrc`가
`/etc/zshrc_$TERM_PROGRAM`을 source하고, 존재하는 파일은 `Apple_Terminal` 것
하나뿐입니다. [06-integration](../06-integration.md)이 요구하는 대로
`TERM_PROGRAM=knotty`를 두는 순간 zsh는 OSC 7을 내보내지 않고, 엔진의 `pwd`는 빈
문자열이 되며, 복원되는 창은 **전부 홈에서** 열립니다. `proc_pidinfo`로
포어그라운드 프로세스의 작업 디렉터리를 직접 읽으면 셸 설정 없이 맞습니다 —
종료 경고가 이미 `tcgetpgrp`로 같은 pid를 잡으므로 물어보는 자리도 같습니다.

**주기적 저장은 B7을 깹니다.** 유휴는 "출력 없음 + 입력 없음"이고, 커서 깜빡임까지
버려 가며 지킨 조건입니다. 영원히 도는 저장 타이머는 그것을 똑같이 깹니다. 사건
기반이면 유휴에 도는 것이 하나도 없으면서 크래시에도 살아남습니다.

## 기각안

**`TERM_PROGRAM=Apple_Terminal`로 위장한다.** 위 규칙 덕에 OSC 7을 공짜로 얻지만,
터미널을 판별하는 다른 모든 프로그램을 함께 속이고 Apple의 셸 세션 파일이 우리
세션 이름으로 쌓입니다.

**셸 통합 스크립트를 배포한다.** Ghostty의 길입니다. 사용자가 `.zshrc`에 한 줄을
넣어야 하고, 넣지 않으면 아무것도 안 한 것과 같습니다.

**⌘Q에만 저장한다.** 유휴는 깨끗하지만 크래시에 잃습니다. 사건 기반이 둘 다
얻으므로 고를 이유가 없습니다.

## 결과

- **이 결정 자체는 ABI를 자라게 하지 않습니다.** `pwd` 필드는 이미 있고 채우는
  규칙만 바뀝니다. 종료 경고의 플래그와 `kt_session_new_pty`의 작업 디렉터리
  인자는 별개 사유로 ABI 9에 들어갑니다.
- **macOS 전용 호출이 `io.rs`에 하나 늘어납니다.** PTY가 이미 있는 파일입니다.
- **tmux 안에서는 여전히 부정확합니다.** 포어그라운드가 tmux 클라이언트라 tmux를
  띄운 자리가 나옵니다. 06-integration이 OSC 7의 한계로 적어 둔 그 자리입니다.
- **`NSQuitAlwaysKeepsWindows`를 읽어 존중합니다.** 시스템 복원을 쓰지 않으면서도
  사용자의 그 설정은 지켜집니다.
- **05-swift-app 9절의 "주기적으로 저장합니다"를 고칩니다.**
