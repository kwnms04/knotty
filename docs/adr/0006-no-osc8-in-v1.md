# v1은 OSC 8 하이퍼링크를 지원하지 않는다

URL 기능은 **⌘ 지연 스캔 자동 감지**만 v1에 넣습니다. 스냅샷 텍스트를 훑어 URL 패턴을 찾는 방식이라 외부 의존이 없습니다. OSC 8 명시 하이퍼링크는 v1 비목표입니다.

## 맥락

VT 엔진의 C API가 하이퍼링크를 충분히 노출하지 않습니다. 확인한 상태(퍼블릭 알파 기준):

- OSC 8 시퀀스 자체는 파싱됩니다 (`osc.h`의 `HYPERLINK_START` / `HYPERLINK_END`).
- 셀 단위 질의로 **불리언 하나**를 얻을 수 있습니다 — `GHOSTTY_CELL_DATA_HAS_HYPERLINK`("이 셀에 하이퍼링크가 있는가"), 행 단위로는 `GHOSTTY_ROW_DATA_HYPERLINK`(거짓 양성 있을 수 있음).
- **링크 id도 URL도 나오지 않습니다.**
- 그리고 이 불리언은 살아 있는 터미널에 질의하는 경로에 있습니다. knotty가 쓰는 **렌더 상태 경로에는 하이퍼링크가 아예 없습니다** — 셀 데이터 키는 RAW / STYLE / GRAPHEMES / BG_COLOR / FG_COLOR / SELECTED / HAS_STYLING이 전부입니다.

따라서 "같은 링크 id를 가진 셀들이 함께 강조"(호버 밑줄)도, "클릭 시 URL 열기"도 구현할 수 없습니다.

## 결과

- 이 제약은 **코드에 드러나지 않습니다.** 엔진 본체 앱은 OSC 8을 지원하므로, 나중에 보면 "왜 안 했지?"로 보입니다. 그래서 기록합니다.
- 업스트림 기여를 병행합니다. 내부에는 데이터가 있으므로 렌더 상태에 id·URL을 노출하는 증분 추가이지 기능 구현이 아닙니다.
- **업스트림을 기다리지는 않습니다.** 알파 프로젝트의 로드맵에 v1 마일스톤을 묶지 않습니다. 노출이 이루어지면 그때 얹습니다.
- 실사용 손실은 제한적입니다. 출력에 찍히는 평문 URL은 ⌘ 스캔이 잡습니다. OSC 8을 실제로 내보내는 것은 `ls --hyperlink`, delta, 일부 CI 로그 정도입니다.
