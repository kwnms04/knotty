# Definition of Done

흩어진 수용 기준의 단일 목록입니다. **모든 항목 충족 = v1 마감.**
각 항목은 검증 방법을 병기합니다.

## A. Features

- [ ] VT100/xterm 핵심. 파서 적합성은 VT 엔진이 보장하므로 우리 검증은 하네스 골든 스냅샷으로 대체합니다 (D절)
- [ ] 256색 + 트루컬러, UTF-8, 스크롤백, 대체 화면, bracketed paste
- [ ] SGR 마우스, 포커스(1004), alternate scroll(1007), 동기화 출력(2026)
- [ ] OSC 0/2, 7, 52(쓰기. 읽기는 빈 응답), 4/10/11(질의 응답 포함)
- [ ] **리거처** — 셰이핑 경로는 GSUB 프로브 결과로 확정 ([R3](04-renderer.md#r3--shaping-unit))
- [ ] URL: ⌘ 지연 스캔 자동 감지, wrapped 줄 이어붙이기
- [ ] 붙여넣기 검사·경고·정화, 제목·아이콘 라벨 질의 빈 응답
- [ ] 창 복원(작업 디렉터리), 종료 경고, ⌘K, Option-as-Meta(좌/우)
- [ ] TOML 설정 + 라이브 리로드. 파싱 에러 시 진단 표시, 기존 설정 유지
- [ ] tmux 수준 1 표의 전 항목 ([06-integration](06-integration.md))

## B. Performance gates

수치 미달은 미완료입니다. 참조 환경은 200×60, 120Hz, Retina.

| # | 기준 | 검증 |
|---|---|---|
| B1 | dirty 10줄 프레임 준비 p99 < 2ms | 렌더러 벤치 (순수 함수 직접 측정) |
| B2 | 전체 무효화 ASCII < 4ms, CJK < 8ms | 상동 |
| B3 | 셰이핑 캐시 적중률 > 99% (스크롤 포함 정상 상태) | 캐시 카운터 |
| B4 | 폭주 출력 중 **스냅샷 수령** p99 < 1ms | 코어 벤치: 폭주 + 주기 수령. 측정 대상은 메일박스 수령이지 락 대기가 아닙니다 |
| B5 | 폭주 중 키 입력 → PTY 기록 지연 p99 < 2ms | 코어 벤치 |
| B6 | 폭주 중 프레임 드랍 0 (120Hz 스크롤) | 수동 + 계측 |
| B7 | 유휴 시 CPU 0%대, GPU 0, 디스플레이 링크 정지. **유휴 = 출력 없음 + 입력 없음**이며, 커서 깜빡임은 v1에서 이 조건을 깨지 않도록 제공하지 않습니다 | Activity Monitor / powermetrics |
| B8 | `time cat 100MB` — 주요 터미널 대비 2배 이내 | 스크립트 |
| B9 | 스크롤백 10만 줄에서 리사이즈 1회 p99 < 8ms | 코어 벤치. 미달 시 리사이즈 비동기화를 검토 |

## C. IME and input

전부 수동 검증이며 시나리오별로 통과를 기록합니다.

- [ ] 한글 두벌식: 조합 중 인라인 표시, 조합 중 백스페이스(자소 단위), 조합 중 Enter/Esc
- [ ] 조합 중 커서 이동 키 — IME 소비와 터미널 전달의 분기 정확성
- [ ] 조합 미확정 상태에서 포커스 이탈 (확정 또는 취소, 그리드 오염 없음)
- [ ] 후보창 위치 = 커서 셀 (스크롤·리사이즈 직후 포함)
- [ ] vim insert 모드 안에서 위 전부 재검증 (+ tmux 안 vim에서 한 번 더)
- [ ] 일본어(변환 후보), 이모지 팔레트(⌃⌘Space) 입력
- [ ] ESC·개행 포함 텍스트 붙여넣기 — 경고 표시 및 정화 확인

## D. Verification infrastructure

이것 자체가 산출물입니다.

- [ ] 헤드리스 하네스: 녹화 스트림(vim, tmux, fzf, lazygit, htop) 10종 이상 → 골든 스냅샷 비교, CI 통합
- [ ] `feed` 퍼저: 24시간 무크래시·무패닉 (defunct 경로 포함)
- [ ] 렌더러 골든 테스트: 하네스 스냅샷 → 인스턴스 버퍼 비교
- [ ] **VT 엔진 버전 고정 + 업그레이드 절차 문서.** 하네스 통과가 승인 조건입니다. 상류가 퍼블릭 알파이므로 이 항목의 비중이 높습니다

## E. Real-world TUI checklist

각 앱에서 표시·마우스·리사이즈·색을 확인합니다.

vim/neovim, tmux(리사이즈 중 리플로우 포함), fzf, lazygit, htop, less, delta, ssh 원격 세션.
원격 tmux에서 OSC 52 복사, 원격에서 제목·아이콘 라벨 질의 시 빈 응답도 함께 확인합니다.

`ls --hyperlink`는 OSC 8을 내보내므로 v1에서 링크로 동작하지 않습니다. 파일명이 평문으로 보이는 것이 정상 동작입니다.

## F. macOS lifecycle

- [ ] sleep/wake 복귀, 디스플레이 연결·해제 (배율 변경 → 리셋 경로)
- [ ] 라이트/다크 자동 전환 — 재드로우만 수행하고 아틀라스 리셋이 없음을 확인
- [ ] 앱 재시작 복원 (창 프레임, 작업 디렉터리)
- [ ] 폭주 출력 중 창 이동·리사이즈·미니마이즈에 UI 응답 유지

## Non-goals

v1에서 만들지도, 검증하지도 않습니다.

스플릿, 탭, **OSC 8 하이퍼링크**, 이미지 프로토콜, kitty keyboard protocol, OSC 133,
스크롤백 검색, GUI 설정창.
