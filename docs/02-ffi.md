# FFI

**참 소스는 생성된 헤더입니다.** 이 문서는 헤더가 지켜야 할 계약을 서술합니다. 실제 시그니처는 M0에서 생성됩니다.

## Global Contract

- 헤더는 Rust 쪽 어노테이션에서 생성됩니다. 생성 결과와 헤더가 다르면 그것은 결함이며, 고칠 곳은 Rust 쪽입니다.
- 가장 먼저 ABI 버전을 핸드셰이크로 확인합니다. 불일치면 기동을 중단합니다.
- **동결의 범위는 ABI입니다.** 기존 심볼의 시그니처·구조체 레이아웃·열거값 의미는 바꾸지 않습니다. 심볼 추가와 구조체 말미 필드 추가는 허용하며, 레이아웃이 바뀌면 ABI 버전을 올립니다.
- 모든 식별자는 불투명 포인터입니다. 내부 타입을 노출하지 않습니다.
- **VT 엔진의 타입·헤더는 경계를 넘지 않습니다.** cf. [0004](adr/0004-hide-vt-engine-types.md)
- 모든 구조체는 C 표현을 적용합니다.
- 패닉은 오류 상태로 변환되어 처리됩니다.
- 세션당 호출이 직렬화됨을 전제로 작성됩니다.

## Input Path

인코딩 자체는 **VT 엔진이 수행합니다.** 코어가 하는 일은 세션 상태를 얹어 엔진의 인코더를 호출하고 결과를 writer 큐에 넣는 것입니다.

| 용도 | 비고 |
|---|---|
| 타이핑, IME 확정 텍스트 | UTF-8 원시 바이트 |
| 붙여넣기 사전 검사 | 순수 함수, 상태 불변. 엔진이 제공 |
| 붙여넣기 | bracketed 래핑과 정화는 무조건 수행. cf. [0007](adr/0007-input-security.md) |
| 특수키 | 커서 키 모드 등에 의존하는 인코딩은 엔진이 수행 |
| 휠 | 마우스 코드 / 방향키 / 스크롤백 3분기 |
| 클릭·드래그 | 리포팅이 꺼져 있으면 무시. 선택은 별도 |
| 포커스 | 포커스 리포팅 모드 게이팅 |
| 리사이즈 | 리플로우 + 창 크기 통지 |
| 팔레트 초기값 주입 | 이후 진실은 코어 |
| `feed` | detached 세션 입력. PTY 세션이면 오류 |

- 쓰기 함수는 큐에 적재되면 PTY 쓰기를 기다리지 않고 반환합니다. cf. [0011](adr/0011-main-thread.md) 계약 A
- writer 큐의 상한은 8MB입니다. 초과 시 호출자에 알립니다.
- 비블로킹 계약의 예외는 둘입니다.
    - `feed` — 호출자 스레드에서 동기적으로 전량 처리합니다. detached 전용이며 결정성이 우선입니다.
    - 리사이즈 — 리플로우 비용이 스크롤백 길이에 비례합니다. 비동기화 대신 [성능 게이트](07-definition-of-done.md#b-performance-gates)로 비용을 묶습니다.

## Output Path (Snapshot)

- 복사 기반이며 값은 변하지 않습니다. 코어가 만들어 **단일 슬롯 latest-wins 메일박스**에 게시하고, App은 받아갑니다. cf. [0003](adr/0003-snapshot-mailbox.md)
- 게시는 처리 단위마다 최대 1회이며, 변경이 없으면 게시하지 않습니다.
- 소비는 파괴적입니다. 새 게시가 없으면 "없음"이 반환됩니다.
- **고정 크기 셀의 행 우선 평탄 배열**입니다. 셀 접근에 함수 호출이 필요 없습니다. cf. [0005](adr/0005-flat-snapshot.md)

셀에 담기는 것:

| 항목 | 내용 |
|---|---|
| 문자 | 코드포인트, 또는 오버플로 시 테이블 인덱스 |
| 전경색·배경색 | **해석된 RGB**. VT 엔진이 팔레트를 이미 해석하며, 지정이 없으면 터미널의 기본색이 대신 실림 |
| 플래그 | 켜짐/꺼짐인 SGR 속성 + 구조 플래그 (전각 앞칸/뒷칸, 오버플로) |
| 밑줄 | 별도 필드. 켜짐/꺼짐이 아니라 종류(없음·단일·이중·물결·점선·파선)이므로 플래그에 두지 않음 |

- 코드포인트가 여럿인 그래핌(결합 문자, ZWJ 이모지)은 오버플로 테이블로 넘깁니다. 테이블은 스냅샷마다 자족적입니다.
- **선택은 셀 밖에 별도로 싣습니다.** 셀 플래그로 두지 않는 이유는 [줄 캐시](04-renderer.md#r2--full-redraw-damage-saves-shaping)의 키가 셀 내용 해시이기 때문입니다 — 선택이 셀 안에 있으면 드래그마다 셰이핑 캐시가 전멸합니다.
- **dirty는 2단**입니다. 전역 상태(변경 없음 / 부분 / 전체)와 행별 플래그. 소비 시 초기화됩니다.
- **소프트 랩 표시** — 각 행에 "그 줄이 다음 줄로 이어지는가"를 싣습니다.
- 커서(위치·표시·모양), 창 제목, 작업 디렉터리를 함께 싣습니다. 제목과 작업 디렉터리는 게시 전 제어 문자를 제거합니다.

## Event Path

판정 기준: **최신 값만 의미 있으면(latest-wins) 스냅샷, 발생 사실 자체가 의미 있으면(exactly-once) 이벤트.** cf. [0003](adr/0003-snapshot-mailbox.md)

| 후보 | 판정 | 근거 |
|---|---|---|
| 벨 | 이벤트 | 발생 자체가 의미 |
| 클립보드 쓰기 (OSC 52) | 이벤트 | 부수효과 명령, 페이로드 동반 |
| 프로세스 종료 | **양쪽** | 유실 불가 → 진실은 스냅샷, 이벤트는 즉시 알림 |
| 창 제목 | 스냅샷 | latest-wins 전형 |
| 커서 모양 | 스냅샷 | 커서 상태의 일부 |
| 팔레트 변경 | 스냅샷 | 셀 색이 이미 해석되어 실림 |
| 대체 화면 전환 | 스냅샷 | 전역 dirty가 이미 그 역할 |
| 작업 디렉터리 | 스냅샷 | 새 창 상속·복원에 필요 |
| 설정 리로드 완료 | 없음 | 로드 함수의 동기 반환이 곧 통지 |

- v1 이벤트는 셋뿐입니다 — 벨, 클립보드 쓰기, 자식 종료. 상태는 스냅샷이, 명령은 입력 경로가 흡수하고 진짜 사건만 남은 결과입니다.
- 이벤트 큐는 유한하며, 드랍되어도 화면은 틀리지 않습니다. 진실이 필요한 사실은 전부 스냅샷에 있습니다.
- wake는 코얼레싱되므로, wake 한 번마다 큐가 빌 때까지 드레인합니다.
- **wake 콜백 안에서는 경계 호출을 금지합니다.** 자기 스레드를 깨우는 것만 허용합니다.
- 클립보드 읽기(OSC 52)는 이벤트가 아니라 무조건 빈 응답입니다. 보안 기본값입니다.

## Config

- 로드 — 파싱·검증·기본값 병합. 실패 시 진단 문자열을 돌려줍니다.
- 직렬화 — JSON 블롭 하나.
- **항목별 게터는 두지 않습니다.** 설정이 늘어도 헤더가 바뀌지 않게 하기 위함입니다.
- 코어에 영향을 주는 설정은 App이 명령 경로로 재주입합니다. v1에서 그 대상은 팔레트뿐이며, 스크롤백 크기는 새 세션 스폰 시에만 반영됩니다.
- 파일 감시는 App이 소유합니다.
