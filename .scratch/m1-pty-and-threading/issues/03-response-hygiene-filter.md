# 응답 위생 필터

Blocked by: 02
Was: #13

## What to build

제목 질의에 대한 응답이 빈 값으로 나갑니다. 신뢰할 수 없는 출력이 창 제목에 명령을 심어 두고 질의로 되돌려 받는 통로를 막습니다 — PTY로 가는 응답은 셸 입장에서 키보드 입력과 구별되지 않습니다.

응답은 비어 있되 나가기는 나갑니다. 무응답이면 답을 기다리는 프로그램이 멈춥니다.

엔진이 이 응답만 콜백 없이 직접 내보내므로, 나가는 바이트가 지나는 단일 지점에서 판정합니다. 아이콘 라벨 질의는 엔진이 구현하지 않아 대상이 아닙니다.

## Acceptance criteria

- [x] 제목을 설정한 뒤 제목 질의를 보내면, 큐에 실린 응답에 그 제목이 들어 있지 않다
- [x] 그럼에도 응답 자체는 나간다
- [x] 제목 질의가 아닌 응답은 손대지 않고 그대로 나간다
- [x] 제목 스택 조작은 쓰기이므로 정상 동작한다
