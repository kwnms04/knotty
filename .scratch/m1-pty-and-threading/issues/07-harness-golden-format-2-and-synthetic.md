# 하네스 확장: 골든 형식 2와 합성 녹화

Blocked by: 03, 04, 05, 06
Was: #17

## What to build

하네스가 화면뿐 아니라 밖으로 나간 것까지 골든에 적습니다. 지금 골든은 화면만 담고 있어서, M1이 만든 응답·이벤트·알림이 전부 무검증입니다.

기존 녹화 넷은 벨·클립보드 쓰기·제목 질의·동기화 출력을 건드리지 않으므로, 그것들을 담은 합성 녹화를 하나 더 둡니다. 유니코드 녹화가 같은 이유로 추가된 선례입니다.

하네스는 프런트엔드가 쓸 것과 같은 공개 C ABI만 사용합니다. 검증하는 길이 앱이 타는 길과 달라지면 안전망이 아닙니다.

**M1 1단의 종료 판정입니다.**

## Acceptance criteria

- [x] 골든 형식의 버전이 올라가고, writer 큐 내용·이벤트 큐 내용·wake 횟수가 새 절로 실린다
- [x] tmux 녹화가 이미 담고 있는 질의들에 대한 응답이 그 골든에 나타난다
- [x] 벨·클립보드 쓰기·제목 질의·동기화 출력 블록을 담은 합성 녹화와 그 골든이 추가된다
- [x] 그 골든이 제목 질의 응답에 제목이 실려 있지 않음을 보인다
- [x] 골든 갱신은 전용 환경 변수를 켠 실행에서만 일어난다
- [x] CI가 모든 골든을 검사한다
