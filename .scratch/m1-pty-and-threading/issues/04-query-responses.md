# 질의 응답

Blocked by: 02
Was: #14

## What to build

자식이 "너 어떤 터미널이냐"고 물으면 답합니다. 지금은 답을 채우는 콜백이 없어 엔진이 침묵하고, 응답을 기다리는 TUI가 그 자리에서 멈춥니다.

코어가 이미 아는 정적인 값만 채웁니다. 픽셀 크기와 색 스킴은 각각 렌더러와 앱이 아는 값이라 콜백을 달지 않고 엔진이 침묵하게 둡니다 — 거짓 값을 지어내지 않기 위함입니다.

## Acceptance criteria

- [x] 장치 속성 1차·2차·3차 질의에 각각 응답이 나간다
- [x] 터미널 이름·버전 질의에 knotty의 값이 나간다 (엔진 기본값이 아니다)
- [x] ENQ에 응답이 나간다
- [x] 픽셀 크기 질의에는 아무것도 나가지 않는다
- [x] 색 스킴 질의에는 아무것도 나가지 않는다
