# B4·B5 벤치

Blocked by: 11, 12
Was: #23

## What to build

출력이 폭주하는 동안에도 화면 한 장 받아오는 시간과 키 입력이 자식에게 도달하는 시간이 기준 안에 듭니다. **M1의 성능 종료 판정입니다.**

재는 것이 부하 중의 꼬리 지연이라 마이크로벤치 프레임워크는 모양이 맞지 않습니다. 시나리오를 직접 구성하고 시각 기록을 모아 백분위를 뽑는, 의존성 없는 바이너리로 만듭니다.

CI에는 넣지 않습니다. 공유 러너의 측정은 이웃 작업에 따라 흔들려 무작위 실패를 낳고, 그것이 게이트를 죽이는 가장 흔한 방식입니다. DoD가 참조 환경을 특정 기계로 못 박아 둔 것도 같은 이유로 읽힙니다.

## Acceptance criteria

- [x] 폭주 부하를 만들고 주기적으로 화면을 수령하는 시나리오를 돌린다
- [x] 폭주 중 키 입력이 자식에게 도달하는 지연을 잰다
- [x] 두 측정 모두 백분위로 보고한다
- [x] DoD가 정한 참조 환경에서 B4와 B5의 기준을 만족한다
- [x] CI의 일반 검사에는 포함되지 않는다
