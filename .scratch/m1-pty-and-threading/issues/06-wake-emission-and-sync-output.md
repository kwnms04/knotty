# wake 방출과 동기화 출력 억제

Blocked by: 05
Was: #16

## What to build

새 화면이나 새 이벤트가 준비되면 등록된 콜백이 불립니다. 소비자가 폴링하지 않고도 그릴 때를 압니다.

자식이 동기화 출력 블록을 여는 동안에는 부르지 않습니다. 그 사이 게시된 중간 화면은 메일박스가 최신만 남기므로 소비자가 보지 않고 지나갑니다. 블록이 끝나면 정확히 한 번 부릅니다.

블록이 끝나지 않을 때 푸는 타임아웃은 시계가 필요해 여기 없습니다. 스레드가 생긴 뒤입니다.

## Acceptance criteria

- [x] 콜백을 등록할 수 있고, 게시할 것이 생기면 불린다
- [x] 게시할 것이 없으면 불리지 않는다
- [x] 동기화 출력 블록이 열려 있는 동안에는 불리지 않는다
- [x] 블록이 닫히면 정확히 한 번 불린다
- [x] detached 세션에서도 같은 규칙으로 불린다
