# CI에 macOS 러너 추가

Blocked by: —
Was: #11

## What to build

CI가 리눅스와 macOS 양쪽에서 돕니다. 지금은 리눅스 하나뿐이라, 실제로 출시할 플랫폼이 자동으로 검사되지 않습니다.

M1이 플랫폼에 의존하는 첫 코드를 들여오기 직전에 세워 둡니다. 나중에 하면 이미 쌓인 PTY 코드를 한꺼번에 검증하게 되고, 어느 변경이 어느 플랫폼을 깼는지 가리기 어려워집니다.

리눅스를 남겨 두는 이유는 따로 있습니다. "코어를 이식 가능하게 유지한다"는 제약은 코드 어디에도 나타나지 않으므로, 리눅스 빌드가 그것을 대신 집행합니다.

## Acceptance criteria

- [x] CI가 리눅스와 macOS 두 러너에서 같은 검사를 수행한다
- [x] 두 러너 모두에서 포맷·린트·테스트가 통과한다
- [x] 한쪽에서만 깨지는 변경이 들어오면 그 러너가 빨간불이 된다
