# 동기화 출력 타임아웃

Blocked by: 09
Was: #22

## What to build

자식이 동기화 출력을 켜놓고 끄지 않아도 화면이 영원히 멈추지 않습니다. 1초가 지나면 풀립니다.

풀린 뒤에는 **그 블록을 포기합니다** — 블록이 정상적으로 끝날 때까지 다시 억제하지 않습니다. 타임아웃마다 한 장씩 내보내는 방식은 얼어붙음을 저속 재생으로 바꿀 뿐이고, 그 프로그램의 화면은 어차피 이미 틀렸으니 사용자가 상황을 볼 수 있는 속도로 그리는 편이 낫습니다.

값을 넉넉히 잡은 이유는 **틀린 발동이 맞는 발동보다 흔하기** 때문입니다. 느린 링크에서는 정상적인 블록 하나가 네트워크를 건너오느라 오래 걸리고, 타임아웃이 짧으면 그때마다 화면이 찢어져 보입니다. 반대로 진짜 버그난 프로그램은 드물고 손해는 한 번뿐입니다.

설정 항목으로 빼지 않고 상수로 둡니다.

## Acceptance criteria

- [x] 블록이 열린 채 정해진 시간이 지나면 알림이 한 번 간다
- [x] 그 뒤로는 블록이 닫힐 때까지 억제하지 않는다
- [x] 블록이 정상적으로 닫히면 억제 규칙이 원래대로 돌아온다
- [x] 정상적인 짧은 블록에서는 타임아웃이 발동하지 않는다
