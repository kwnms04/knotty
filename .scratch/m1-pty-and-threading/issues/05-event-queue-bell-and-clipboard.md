# 이벤트 큐: 벨과 클립보드 쓰기

Blocked by: 02
Was: #15

## What to build

자식이 벨을 울리거나 클립보드에 복사해 달라고 하면 그 사실이 앱으로 나갑니다. 화면에 남지 않고 발생 자체가 의미인 것들이라 스냅샷이 아니라 큐로 갑니다.

큐는 유한하고 넘쳐 버려진 개수를 셉니다. 이벤트가 유실되어도 화면은 틀리지 않습니다 — 진실이 필요한 것은 전부 스냅샷에 있습니다.

클립보드 읽기 요청은 엔진이 우리에게 전달하지 않고 버립니다. 따라서 응답을 만들 수단이 없고, 실제 동작은 무응답입니다.

## Acceptance criteria

- [x] 벨 시퀀스를 먹이면 이벤트가 큐에 쌓인다
- [x] 클립보드 쓰기 시퀀스를 먹이면 대상과 내용이 함께 이벤트로 쌓인다
- [x] 클립보드 내용에 크기 상한이 걸린다
- [x] 큐에 상한이 있고, 넘쳐 버려진 개수를 읽을 수 있다
- [x] detached 세션에서 이벤트를 꺼낼 수 있고, 꺼내면 큐가 비워진다
- [x] 클립보드 읽기 요청에는 아무것도 나가지 않는다
