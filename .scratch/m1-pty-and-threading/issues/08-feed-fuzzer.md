## What to build

어떤 바이트를 밀어 넣어도 코어가 패닉하지 않습니다. 자식이 깨진 이스케이프 시퀀스를 뱉는 일은 흔하고, 그때 앱이 죽으면 안 됩니다.

대상은 호출 하나가 아니라 세션 수명 전체의 순환입니다 — 먹이고, 화면을 꺼내고, 큐를 비우고, 다시 먹이는 것.

일반 PR 경로에는 넣지 않습니다. 커버리지 유도 퍼저가 요구하는 툴체인이 평소 CI에 들어오지 않아야 합니다.

## Acceptance criteria

- [x] 퍼즈 타깃이 세션을 만들고, 임의 바이트를 먹이고, 스냅샷과 두 큐를 꺼내는 순환을 돈다
- [x] 별도 CI 잡에서 실행되며 일반 PR 검사에는 포함되지 않는다
- [x] 1시간 실행에서 크래시와 패닉이 없다
- [x] 발견된 입력이 코퍼스로 남고 재현할 수 있다
