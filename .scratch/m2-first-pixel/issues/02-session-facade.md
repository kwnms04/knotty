# 세션 파사드: detached 세션과 스냅샷 뷰

Blocked by: 01
Was: #33

## What to build

앱이 코어와 대화할 수 있게 됩니다. 세션 핸들을 만지는 객체가 하나 생기고, 그 객체만이 경계를 부릅니다.

이 티켓이 다루는 것은 PTY 없는 detached 세션입니다. 스레드도 자식 프로세스도 없어 결과가 결정적이고, 파서 이후의 경로는 PTY 세션과 같은 코드이므로 여기서 고정된 것은 나중에 실제 셸에서도 그대로 참입니다. **Swift 테스트 이음매가 여기서 섭니다** — 이후 티켓들이 검증에 쓰는 길이 이것입니다.

스냅샷은 복사하지 않고 빌립니다. 파사드가 뷰를 여는 스코프를 제공하고, 포인터는 그 스코프 안에서만 유효하며, 나가는 길에 해제가 일어납니다. 스냅샷은 이미 코어가 만든 복사본이므로 한 번 더 복사하면 O(1) 수령이라는 전제가 깨집니다. 제목이나 작업 디렉터리를 프레임 밖으로 들고 나가려면 문자열로 복사해야 하고, 그것이 경계 계약이 요구하는 행동입니다.

이벤트 큐도 여기서 비웁니다. 무엇을 할지에 대한 정책은 아직 없지만 큐는 유한하고, 알림 하나마다 빌 때까지 꺼내는 것이 경계의 계약입니다. 지금은 꺼내서 버립니다.

셀과 행 타입은 별칭으로 바깥에 노출됩니다. 그리는 쪽이 레이아웃 사본을 만들지 않으면서도 C 경계를 import하지 않는 방법입니다.

## Acceptance criteria

- [x] detached 세션을 만들고 바이트를 먹이고 해제할 수 있다
- [x] 하네스 녹화를 먹인 뒤 그리드 크기, 셀 내용, 커서가 스냅샷에서 읽힌다
- [x] 자식 상태와 세션 상태를 프레임을 꺼낸 뒤에 읽는다
- [x] 스냅샷 뷰의 유효 범위가 스코프로 제한되고, 나가는 길에 해제된다
- [x] 이벤트를 큐가 빌 때까지 꺼낼 수 있고, 넘쳐 버려진 개수를 함께 받는다
- [x] 세션을 여러 번 만들고 해제해도 누수가 없다
- [x] 위 전부가 GPU도 창도 없이 `swift test`로 검증된다
