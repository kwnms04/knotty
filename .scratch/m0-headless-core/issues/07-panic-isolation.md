# 07 — 패닉 격리와 오류 코드

**What to build:** 코어 안에서 무언가 터져도 프로세스가 죽지 않습니다. 목표는 "터미널 하나가 죽어도 앱은 산다"이며, 죽은 세션은 마지막으로 옳았던 화면을 유지한 채 더 이상 입력을 받지 않습니다.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 코어 내부에서 패닉이 발생해도 프로세스가 종료되지 않는다
- [ ] 패닉이 구분 가능한 오류 코드로 호출자에게 전달된다
- [ ] 패닉한 세션의 스냅샷은 마지막 정상 상태를 유지한다
- [ ] 패닉 이후 그 세션에 대한 입력은 오류를 반환한다
- [ ] 실패 사유가 코드로 구분된다 — 무효한 핸들, 잘못된 인자, 패닉 등
- [ ] PTY가 붙은 세션에 `feed`를 호출하는 경우의 오류가 정의되어 있다 — M0에는 그런 세션이 없지만 계약은 지금 고정한다
