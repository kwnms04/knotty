# 03 — 그래핌 오버플로와 전각

**What to build:** 코드포인트가 여러 개인 문자와 두 칸을 차지하는 문자가 손실 없이 스냅샷에 표현됩니다. 셀은 고정 크기를 유지해야 하므로, 셀에 담기지 않는 것은 별도 테이블로 넘깁니다.

**Blocked by:** 01

**Status:** ready-for-agent

- [x] 전각 문자의 앞칸과 뒷칸이 서로 다른 표시로 구분된다
- [x] 별도 테이블은 스냅샷마다 자족적이다 — 이전 스냅샷을 참조하지 않는다
