# 04 — dirty 2단과 소프트 랩

**What to build:** 무엇이 바뀌었는지를 스냅샷이 알려줍니다. 나중에 렌더러가 변경된 줄만 다시 그릴 수 있어야 하고, 줄 이어붙이기가 필요한 곳에서 소프트 랩과 강제 개행을 구분할 수 있어야 합니다.

**Blocked by:** 01

**Status:** ready-for-agent

- [x] 변경 없음 / 부분 변경 / 전체 변경의 전역 상태가 읽힌다
- [x] 부분 변경일 때 어느 행이 바뀌었는지 행 단위로 읽힌다
- [x] 대체 화면 전환처럼 화면 전체가 바뀌는 상황이 전체 변경으로 보고된다
- [x] 각 행에 "이 줄이 다음 줄로 이어지는가"가 실린다
- [x] 강제 개행으로 끝난 줄과 화면 폭에 걸려 넘어간 줄이 구분된다
- [x] dirty 표시는 스냅샷을 소비할 때 초기화되어 다음 스냅샷에 누적되지 않는다
