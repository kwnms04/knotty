# 08 — 하네스: 골든 스냅샷

Blocked by: 02, 03, 04, 05, 06
Was: #9

**What to build:** 실제 TUI 앱의 출력을 녹화해 두고 재생한 뒤, 나온 스냅샷을 저장된 기대값과 대조합니다. 이것이 M0의 종료 판정이자, 이후 VT 엔진 버전을 올릴 때의 안전망입니다. 버그가 코어의 것인지 상류의 것인지도 여기서 갈립니다.

하네스는 프런트엔드가 쓸 것과 **같은 공개 C ABI만** 사용합니다. 그래야 검증하는 길과 앱이 타는 길이 같습니다.

- [x] 녹화된 바이트 스트림 파일을 재생해 스냅샷을 만든다
- [x] vim·tmux·htop 세 종의 녹화가 포함된다
- [x] 스냅샷을 골든과 바이트 단위로 비교한다
- [x] 불일치 시 어느 행·열이 어떻게 다른지 사람이 읽을 수 있는 형태로 출력한다
- [x] 골든을 갱신하는 명시적 수단이 있고, 기본 실행은 골든을 쓰지 않는다
- [x] CI에서 자동으로 돌고, 실패하면 빌드가 깨진다
- [x] 하네스가 공개 C ABI 밖의 내부 항목에 접근하지 않는다
