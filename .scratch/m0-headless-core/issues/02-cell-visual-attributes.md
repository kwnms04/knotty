# 02 — 셀 시각 속성

**What to build:** 색과 서식 시퀀스를 먹였을 때 그 결과가 스냅샷의 셀에서 읽힙니다. 색은 이미 해석된 RGB로 나오므로 소비자가 팔레트를 다시 들여다볼 필요가 없습니다.

**Blocked by:** 01

**Status:** ready-for-agent

- [x] 지정한 전경색과 배경색이 해석된 RGB 값으로 셀에서 읽힌다
- [x] 기본색, 256 팔레트 색, 트루컬러가 모두 RGB로 나온다
- [x] 굵게·흐리게·기울임·밑줄·깜빡임·반전·숨김·취소선·윗줄이 각각 구분되어 읽힌다
- [x] 밑줄 스타일의 종류가 구분되어 읽힌다
- [x] 팔레트를 바꾸는 시퀀스 이후에 게시된 스냅샷의 셀 색이 갱신되어 있다
