# 01 — 트레이서: detached 세션에 바이트를 넣고 스냅샷을 꺼낸다

Blocked by: —
Was: #2

**What to build:** PTY 없이 터미널 세션을 만들고, ASCII 바이트를 밀어 넣고, 결과 화면을 스냅샷으로 꺼내 읽는 경로 하나를 공개 C ABI로 관통시킵니다. 이 경로가 서면 이후 티켓은 전부 여기에 필드를 더하는 일이 됩니다.

가장 얇은 경로지만 우회로는 없습니다. detached 세션도 메일박스를 지나므로, 최소 구성에도 게시·소비가 들어갑니다.

- [x] detached 세션을 생성하고 해제할 수 있으며, 핸들은 내부 구조를 드러내지 않는 불투명 포인터다
- [x] 기동 시 ABI 버전을 확인할 수 있고, 헤더와 라이브러리가 어긋나면 호출자가 감지한다
- [x] `feed`는 호출한 스레드에서 동기적으로 전량 처리하고 반환한다
- [x] `feed` 직후 스냅샷을 꺼내면 그리드 치수와 각 셀의 ASCII 문자가 읽힌다
- [x] 스냅샷은 고정 크기 셀의 행 우선 평탄 배열이며, 셀 접근에 함수 호출이 필요 없다
- [x] 새로 게시된 것이 없는 상태에서 꺼내면 "없음"이 반환된다
- [x] 소비되지 않은 스냅샷 위에 새로 게시하면 이전 것이 버려진다 — 생산자와 소비자가 동시에 도는 상황에서 검증한다
- [x] VT 엔진의 타입·헤더가 공개 C ABI에 나타나지 않는다
- [x] 헤더가 생성되며, 생성 결과와 소비 측이 일치한다
