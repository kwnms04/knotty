# 링크를 연다

Blocked by: 05

## What to build

⌘를 누르면 화면의 URL에 밑줄이 그어지고, ⌘클릭이 기본 브라우저에서 엽니다.

**스캔은 앱이 합니다.** [01-architecture](../../../docs/01-architecture.md#ownership)
소유권 표가 "URL 클릭 정책"을 앱에 두고 있고, 스냅샷의 `cells`·`graphemes`·
`row_state`로 텍스트를 재구성할 수 있습니다. 접힌 줄은 `KT_ROW_FLAG_WRAPPED`로
잇습니다. ABI가 자라지 않습니다.

**`http://`와 `https://`만 인식합니다.** 터미널 화면은 점 찍힌 토큰으로 가득해서,
scheme 없는 도메인까지 잡으면 `Cargo.toml`·`main.rs`·`v1.2.3`이 전부 링크가 됩니다 —
⌘를 눌렀을 때 화면 절반에 밑줄이 그어지면 기능이 신호가 아니라 소음입니다.

**⌘가 눌린 동안에만 스캔하고 그립니다.** 지연 스캔이라 평소에는 비용이 없습니다.
⌘가 눌린 클릭은 마우스 리포팅보다 우선하므로, 리포팅이 켜진 프로그램 안에서도
링크가 열립니다.

밑줄은 05가 세운 사각형 패스를 그대로 씁니다.

## Acceptance criteria

- [ ] ⌘를 누르면 URL에 밑줄이 그어진다
- [ ] ⌘를 떼면 사라진다
- [ ] ⌘클릭이 기본 브라우저에서 연다
- [ ] 접힌 줄에 걸친 URL이 하나로 인식된다
- [ ] scheme 없는 토큰에는 밑줄이 그어지지 않는다
- [ ] 마우스 리포팅이 켜진 프로그램 안에서도 ⌘클릭이 링크로 간다
