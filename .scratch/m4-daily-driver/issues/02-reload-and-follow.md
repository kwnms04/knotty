# 설정이 바뀌면 따라간다

Blocked by: 01

## What to build

파일을 저장하면 앱을 다시 켜지 않고 반영됩니다. **파일 감시는 앱이 소유합니다**
(디바운스 ~200ms). 리로드 뒤 diff해서 항목별로 적용합니다. cf.
[05-swift-app 10절](../../../docs/05-swift-app.md#10--config-pipeline)

**폰트 크기가 바뀌면 그리드를 유지하고 창을 조정합니다.** 근거는 리플로우가 아예
일어나지 않는다는 것입니다 — 그리드가 그대로면 `SIGWINCH`도 리플로우도 없고,
B9(스크롤백 10만 줄 리사이즈)를 폰트를 바꿀 때마다 내지 않습니다. 반대로 하면
그리드가 바뀐 뒤 반 칸을 없애려고 창을 다시 스냅해야 해서 "창을 유지한다"가
사실이 아니게 됩니다. Terminal.app과 iTerm2의 기본 동작도 이쪽입니다.

새 크기가 화면에 안 들어가면 들어갈 만큼 그리드를 줄입니다.

**파싱 에러는 창 상단 배너입니다.** 시트는 모달이라 화면을 막는데, 설정 오타는
고치는 동안 그 터미널을 계속 봐야 합니다. 기존 설정이 유지됩니다.

## Acceptance criteria

- [ ] 저장하면 다시 켜지 않고 폰트가 바뀐다
- [ ] 크기가 바뀌면 열·행 수가 유지되고 창 크기가 따라 바뀐다
- [ ] 새 창 크기가 화면을 넘으면 그리드가 줄어든다
- [ ] 파싱 에러에 배너가 뜨고 직전 설정이 유지된다
- [ ] 배너가 화면을 막지 않는다
- [ ] 짧은 간격의 연속 저장이 한 번의 리로드로 합쳐진다
