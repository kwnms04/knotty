# 밑줄을 그린다

Blocked by: —

## What to build

밑줄이 그어진 텍스트에 밑줄이 보입니다. 스냅샷은 종류까지 싣고 있는데 렌더러가
읽지 않습니다 — **M3을 몰아본 패스가 같은 문자열을 Ghostty에 그려 대조했을 때
유일하게 달랐던 셀**이 이것입니다.

데코레이션은 사이 패스의 사각형이고, 커서가 쓰는 것과 같은 패스입니다. cf.
[04-renderer](../../../docs/04-renderer.md)

**v1은 다섯 종류를 구분하지 않고 전부 단일 실선으로 그립니다.** `NONE`이면 그리지
않습니다. 이중·물결 렌더링은 open-questions의 v1.5 항목이고, 셀 플래그가 이미
다섯을 구분해 실려 오므로 나중에 그리는 쪽만 늘리면 됩니다.

## Acceptance criteria

- [ ] 밑줄 속성이 붙은 셀에 밑줄이 그려진다
- [ ] `NONE`인 셀에는 그려지지 않는다
- [ ] 다섯 종류가 전부 단일 실선으로 그려진다
- [ ] wide 문자의 밑줄이 그 문자가 받은 두 칸을 덮는다
- [ ] 렌더러 골든이 밑줄을 서술한다
