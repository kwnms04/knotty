# 창을 여럿 연다

Blocked by: —

## What to build

⌘N으로 새 창을 열고 ⌘W로 그 창만 닫습니다. 지금은 `AppDelegate`가 기동 시 컨트롤러
하나를 만들고 메뉴에 Quit·Copy·Paste뿐이라 **새 창을 여는 길이 없습니다.**

`AppDelegate`가 컨트롤러 목록을 듭니다. `spawningShell()`이 이미 팩토리라 새로 만들
것은 메뉴 항목과 배열입니다.

**마지막 창이 닫혀도 앱은 남습니다.** 창이 0개일 때 Dock 아이콘을 누르면 새 창이
열립니다.

**창 제목이 스냅샷의 `title`을 따릅니다.** 지금 `"knotty"` 상수로 박혀 있습니다.
[06-integration](../../../docs/06-integration.md)이 제목을 "자체 탭이 없는 환경에서
macOS 창을 구별하는 수단"이라고 적었는데, 창이 여럿이 되는 이 티켓이 그 문장이
성립하는 자리입니다. 제목이 비면 앱 이름으로 떨어집니다.

## Acceptance criteria

- [ ] ⌘N이 새 창을 열고 각 창이 자기 셸을 가진다
- [ ] ⌘W가 그 창만 닫고 나머지는 남는다
- [ ] 마지막 창을 닫아도 앱이 살아 있다
- [ ] 창이 하나도 없을 때 Dock 아이콘이 새 창을 연다
- [ ] 창 제목이 스냅샷의 제목을 따른다
- [ ] 제목이 비면 앱 이름으로 떨어진다
