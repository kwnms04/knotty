# 돌고 있을 때만 경고한다

Blocked by: 06

## What to build

`make`가 도는 창을 닫으려 하면 경고가 뜨고, 프롬프트만 떠 있으면 조용히 닫힙니다.

**`child_state`만으로는 안 됩니다.** 셸이 살아 있는 한 그 값은 RUNNING이라, 빈 창을
닫아도 "실행 중인 프로세스가 있습니다"가 뜹니다. 매번 뜨는 경고는 곧 무시되고,
그러면 정작 오래 걸리는 작업이 돌 때도 그냥 닫힙니다.

**포어그라운드 프로세스 그룹으로 판정합니다.** `tcgetpgrp(pty)`가 셸의 프로세스
그룹과 다르면 뭔가 돌고 있는 것입니다.

**스냅샷 필드가 아니라 조회 심볼이 됐습니다.** 시작해서 닫힐 때까지 아무것도
출력하지 않는 작업 — 출력을 파일로 돌린 `make`, `sleep` — 은 프레임을 한 장도 내지
않아서, 손에 든 마지막 프레임은 그 작업이 시작되기 전에 뜬 것이고 조용하다고
말합니다. 경고가 있어야 할 바로 그 경우에 안 뜨는 것입니다. 닫는 시점에 물으면
답이 지금의 것이고, 묻는 자리가 그때뿐이라 유휴에 도는 것도 없습니다(B7).
05-swift-app 8절을 그렇게 고쳤습니다.

**이름은 붙이지 않습니다.** "실행 중인 프로그램이 있습니다"까지가 v1이고, 무엇인지
말하는 것은 open-questions의 v1.5 항목입니다.

**스폰 환경에 `COLORTERM=truecolor`와 `TERM_PROGRAM=knotty`를 함께 답니다.** 지금
`io.rs`가 `TERM`만 설정합니다. 같은 스폰 자리이고,
[06-integration](../../../docs/06-integration.md#level-1-requirements) 표의 환경
항목입니다.

## Acceptance criteria

- [x] 포어그라운드가 셸이면 조회가 거짓을 답한다
- [x] 자식 프로그램이 도는 동안 조회가 참을 답한다
- [ ] 돌고 있는 창을 닫으려 하면 경고가 뜬다
- [ ] 돌고 있지 않은 창은 경고 없이 닫힌다
- [ ] ⌘Q는 창 중 하나라도 돌고 있으면 경고한다
- [x] 자식 환경에 `TERM`·`COLORTERM`·`TERM_PROGRAM`이 있다

체크된 셋은 Swift 테스트가 덮습니다. 남은 셋은 코드가 서 있고(`windowShouldClose`,
`applicationShouldTerminate`) **수동 확인 대기**입니다 — AppKit 경고창은 이 환경에서
자동으로 띄워 볼 수 없습니다. 스펙 Testing Decisions의 "수동" 칸입니다.
