# 설정을 읽는다

Blocked by: —

## What to build

`~/.config/knotty/config.toml`에 폰트를 적으면 그 폰트로 창이 뜹니다. 지금은
`FontFace.preferredName`과 `TerminalWindowController.pointSize`가 상수라 바꾸려면
다시 빌드해야 합니다. 그것이 M4가 설정을 뿌리에 두는 이유 전부입니다.

**`knotty-config` 크레이트가 신설됩니다.** TOML 파싱·검증·기본값 병합이 거기
있고, 경계로 나가는 것은 **JSON 블롭 하나**입니다. 항목별 게터를 두지 않는 이유는
설정이 늘어도 헤더가 바뀌지 않게 하는 것입니다. cf.
[02-ffi](../../../docs/02-ffi.md#config)

**v1 설정은 8키 4그룹이고 스키마는 여기서 전부 섭니다** — `font.family`·`font.size`,
`theme.background`·`foreground`·`cursor`·`palette`, `terminal.option-as-meta`,
`bell.mode`. 이 티켓이 실제로 쓰는 것은 `font`뿐이고 나머지는 통과만 합니다.
문서가 "설정 가능"으로 적어 두었던 나머지(클립보드 삼단, 붙여넣기 경고 삼단, 자식
종료 정책, 스크롤백 크기)는 상수로 내려갔습니다.

파일이 없으면 기본값으로 뜹니다. 파싱이 실패하면 진단 문자열이 돌아옵니다 — 첫
로드에는 유지할 직전 설정이 없으므로 기본값으로 뜬 뒤 진단을 보입니다.

**ABI가 8에서 9로 오릅니다.** 이 마일스톤에서 심볼을 더하는 티켓 여럿 중 먼저
도착한 것이 버전을 올리고, 나머지는 9 안에서 더합니다.

## Acceptance criteria

- [ ] 설정 파일에 적은 폰트 이름과 크기로 창이 뜬다
- [ ] 파일이 없으면 기본값으로 뜬다
- [ ] 빠진 항목이 기본값으로 채워진다
- [ ] 잘못된 값이 진단 문자열로 돌아오고 앱이 죽지 않는다
- [ ] 경계로 나가는 것이 JSON 블롭 하나이고 항목별 게터가 없다
- [ ] ABI 버전이 9로 오르고 핸드셰이크가 통과한다
