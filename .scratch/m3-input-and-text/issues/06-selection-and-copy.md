# 선택과 복사

Blocked by: 05

## What to build

끌어서 고르고 ⌘C로 복사합니다.

**05 다음이어야 합니다.** 리포팅 분기가 서기 전에 선택을 만들면 "이 클릭이 선택인가 보고인가"를 나중에 다시 만지게 됩니다.

**제스처의 상태는 뷰에 셋만 둡니다** — 앵커 셀, 클릭 수, 드래그 중인지. `NSEvent`가 이미 정확하게 주는 값입니다. **무엇이 선택되는지는 코어가 정합니다** — 워드·라인 경계는 엔진의 유니코드 규칙이고, 뷰는 그것을 다시 계산하지 않습니다. cf. [0017](../../../docs/adr/0017-semantic-input-events.md).

**선택 명령은 앵커와 현재 셀을 함께 받습니다.** 셀 하나만 받으면 더블클릭 후 드래그가 공백이나 문장부호 위에서 깜빡이거나 무너집니다. 엔진이 이 문제를 위해 별도 함수를 두고 있습니다.

기존 `kt_session_set_selection`은 그대로 둡니다. 제스처가 아닌 선택 지정의 경로이고 이미 동작합니다.

오토스크롤은 앱의 타이머입니다. 마우스가 멈춰 있어도 계속 스크롤해야 하므로 이벤트로는 만들 수 없고, 방향 판정도 앱이 합니다.

선택 하이라이트는 배경 패스에서 그립니다. 선택이 셀 밖에 실려 오므로 줄 캐시 키에 들어가지 않습니다 — 안에 있으면 드래그 한 번에 캐시가 전멸합니다.

복사는 평문 하나입니다. 엔진이 VT·HTML도 낼 수 있지만 v1의 클립보드 표현은 `text/plain` 하나입니다.

## Acceptance criteria

- [ ] 끌어서 텍스트를 고르고, 고른 부분이 칠해진다
- [ ] 더블클릭이 단어를, 트리플클릭이 줄을 고른다
- [ ] 더블클릭 후 드래그가 단어 단위로 늘어나며 공백 위에서 깜빡이지 않는다
- [ ] ⌥를 누르고 끌면 사각형으로 고른다
- [ ] 창 밖으로 끌면 화면이 따라 스크롤한다
- [ ] ⌘C가 고른 것을 클립보드에 넣고, 접힌 줄이 한 줄로 붙는다
- [ ] 출력이 쏟아져 선택이 스크롤백으로 밀려도 같은 텍스트를 가리킨다
- [ ] 다른 곳을 클릭하면 선택이 풀린다
- [ ] 드래그 중 셰이핑 캐시가 무효화되지 않는다
