# 붙여넣기

Blocked by: 02

## What to build

⌘V가 클립보드의 텍스트를 셸에 넣고, 위험하면 먼저 경고합니다.

**검사·정화·래핑은 전부 엔진 것을 그대로 씁니다.** 개행과 `ESC[201~`를 판정하는 것과, 위험 제어 바이트를 공백으로 치환하고 bracketed 래핑과 개행→CR 변환을 하는 것이 이미 있습니다. 우리가 만들 것은 없습니다. cf. [0007](../../../docs/adr/0007-input-security.md).

사전 검사는 **세션을 받지 않는 순수 함수**입니다. 경고 UI가 붙여넣기 전에 판정을 얻는 길입니다.

경고 시트는 앱이 소유하고 기본은 "멀티라인만"입니다. 미리보기를 포함합니다. 설정 파이프라인은 M4이므로 정책은 여기서 상수입니다.

**경고는 끌 수 있지만 정화는 끌 수 없습니다.** 정화가 붙여넣기 심볼 안에 있고 우회 경로가 없다는 것이 그 집행입니다.

## Acceptance criteria

- [x] ⌘V가 클립보드의 텍스트를 셸에 넣는다
- [x] 붙여넣은 텍스트가 bracketed paste로 감싸여 셸이 텍스트로 받는다
- [x] 개행이 있으면 실행 전에 경고 시트가 뜨고 무엇이 들어갈지 미리 보인다
- [x] 경고를 무시하고 진행해도 위험한 제어 문자는 걸러진다
- [x] 내용에 `ESC[201~`가 있어도 래핑이 깨지지 않는다
- [x] 정화를 우회하는 경로가 없다
- [x] 정화 결과가 골든에 남는다
